# BIRD NPL lineage - synthetic corpus for the semantic lineage classifier

Canonical lineage spec (answer key) for the NPL ratio KRI, built from the official ECB BIRD metadata
export, and the starting point for rendering the synthetic test corpus (SQL, metadata, documents).

- KRI: FINREP F 18.00.a row 0070 - non-performing (C0060) / gross carrying amount (C0010)
- Source: official BIRD export, FINREP 4.3, in `data/raw/`
- Spec: `specs/npl_ratio_lineage_spec_v0.2.yaml` (generated by `src/build_spec_official.py`)

## Setup

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/build_spec_official.py  # extracts the export and regenerates the spec
```

## Working with Claude Code

`CLAUDE.md` holds the standing rules. Task prompts are in `prompts/`; paste one into a Claude Code session,
starting with `prompts/01_setup_check.md`. Decisions on open issues go in `decisions.md`.
