## Corpus design decisions (Task 03)

| Issue | Topic | Status | Decision | Date | Decided by |
|-------|-------|--------|----------|------|------------|
| D1 | Source of the lineage JSON | DECIDED | The lineage JSON is not generated by this project. The project owner runs the corpus SQL through the lineage tool and brings the output back. Task 03 delivers SQL the tool can ingest; checking the tool output against the spec is a later task. | 2026-11-11 | project owner |
| D2 | Naming in the corpus SQL | DECIDED | Keep the BIRD table names (the column names stay as in the reference SQL). No client-style renaming. | 2026-11-11 | project owner |
| D3 | Sources for the regulatory documents | DECIDED | Use the BIRD export and also official legal text (e.g. FINREP Annex V and the reporting ITS from EUR-Lex). Document every referenced regulatory document in one register, and create one general vocabulary glossary. | 2026-11-11 | project owner |
| D4 | Detail of the reporting-chain document | DECIDED | For now, follow the transformation steps closely (one section per step), to make the clustering easy. A coarser variant may be added later. | 2026-11-11 | project owner |
| D5 | SQL dialect of the corpus | DECIDED | The lineage tool reads T-SQL, so the corpus SQL is rendered as T-SQL from the DuckDB reference SQL (sqlglot). Context values use `SESSION_CONTEXT`. No SQL Server is available, so the T-SQL is verified by T-SQL parsing and a round trip back to DuckDB that must reproduce the reference cells exactly (deviation from CLAUDE.md rule 7, which asks for execution in DuckDB). | 2026-11-11 | project owner |
| D6 | Blocking taxonomy labels in the corpus (rule 6) | DECIDED | Multi-word labels are blocked as phrases in any case. Single-word labels (MEASUREMENT, AGGREGATION, TECHNICAL) are blocked only in label form (upper-case/underscore, or as a heading), because verbatim BIRD text uses these words. Taxonomy definition sentences are blocked verbatim. Hand-written prose also avoids the single words. | 2026-11-11 | project owner |
| D7 | Source of legal text | DECIDED | EUR-Lex refuses scripted downloads. The project owner saves the legal text (Implementing Regulation (EU) 2021/451 with Annex V) into `data/raw/legal/`, which is read-only like the BIRD export. Extracts are taken from that file by paragraph number, never retyped. | 2026-11-11 | project owner |
